# KnowLens.ai 可用性测试清单（MVP 上线版）

## 0. 测试目标与范围
- 目标：验证核心用户从“进入站点 -> 登录 -> 输入内容 -> 生成海报/PPT/视频 -> 下载”的完整可用性。
- 范围：Web 端（桌面 Chrome/Safari/Edge，移动端 iOS Safari / Android Chrome）。
- 不在本清单内：大规模压测、深度安全渗透、SEO外链质量。

## 1. 测试环境与前置条件
- 环境：
  - 本地：`http://localhost:3000`
  - 线上：`https://knowlens.ai`
- 账号：
  - 免费用户账号 1 个
  - 付费用户账号 1 个（有有效订阅）
- 支付：
  - Stripe 价格 ID 已配置（Starter/Creator/Pro，月付/年付）
  - `STRIPE_SECRET_KEY` 生效
- 模型：
  - 免费模型与付费模型 API key 已配置
  - image2 接口变量已配置（endpoint/apiKey/model）
- 媒体样本：
  - PDF、DOCX、PPTX、PNG/JPG、MP3、MP4
  - YouTube 链接 1 条（可公开访问）
  - Podcast 链接 1 条（可公开访问）

## 3. 核心可用性验收用例

### A. 落地页与功能首页
1. 打开首页，首屏标题显示完整，不被裁切，视觉层级清晰。
2. Hero 图片可见、加载不闪烁，骨架屏后平滑显示。
3. 点击主 CTA 可进入登录/工作台流程，无空白页。
4. 功能首页输入框可聚焦、可输入、可粘贴文本。
5. 所有可点击按钮 hover/active/cursor 手势一致。
6. Featured Cases 瀑布流滚动时，已加载图片不应回流抖动。
7. 点击 Case 预览弹窗：先有占位，再显示图片。
8. 关闭预览后返回原滚动位置，不应重置到顶部。

### B. 登录与会话保持
9. Google One Tap 在支持浏览器可正常触发。
10. 不支持 One Tap 场景自动回退标准 Google 登录按钮。
11. Google 授权成功后可回到 `/app` 或目标页。
12. OAuth 失败时显示简洁错误文案 + 错误码（错误码弱化展示）。
13. 登录态跨刷新保留（老用户不应频繁重新登录）。
14. 本地开发专用“跳过登录”入口仅在本地可见（线上不可见）。

### C. 会员页与支付
15. 仅展示 3 档会员（Starter/Creator/Pro），无 Studio/Team/API/Enterprise。
16. 月付/年付切换正确，年付显示 `Save 30%`。
17. 点击订阅应跳转 Stripe 页面，不应报 API key 错误。
18. Stripe 取消支付后回跳提示明确，状态不脏。
19. Stripe 支付失败（卡失败）提示明确，不误加积分。
20. Stripe 网络中断后可重试，不产生重复扣费。
21. 支付成功后订阅状态与积分到账正确。
22. `/profile` 是唯一订阅/积分管理入口，可直达。

### D. 输入与上传体验
23. 纯文本输入：空输入不可提交；超字数时才提示（不常驻计数）。
24. 文本字符上限按当前设定生效（例如 6000）。
25. 文件上传支持点击上传、拖拽上传、粘贴上传。
26. 文件卡片仅显示：文件名、格式、大小；名称过长截断不破版。
27. 上传多文件横向滚动正常，卡片尺寸一致。
28. 上传失败不保留脏占位，错误通过 toast 或明确提示输出。
29. 链接上传一次仅允许 1 条；已有链接时入口禁用逻辑正确。
30. 上传文件与链接在对话历史中可见（仅成功项进入主对话流）。

### E. 对话流步骤与引导
31. Step 流程顺序稳定：输入 -> 方向 -> 文稿 -> 风格 -> 账单 -> 生成 -> 下载。
32. 模糊需求（如 “hello”）先出建议卡片，不直接进方向配置。
33. 建议卡片说明“为什么给建议”，并允许用户手动重输。
34. 用户手动重输后，旧建议卡仅保留历史不可再次点击。
35. 方向卡（Poster/PPT/Video）在切换后不消失，状态可见。
36. Next 按钮可点击逻辑正确：缺失配置时给出明确提示。
37. 每次进入下一阶段时有可感知的 thinking/loading，不闪退。
38. 自动滚动行为正确：新卡片出现后视口定位到可见区域。

### F. 文稿与风格阶段
39. 文稿内容应来自真实模型响应，不是静态假数据。
40. 文稿卡片保留在历史中，切到 style 后仍可查看。
41. 风格 12 张图片均为最新素材，比例显示完整不裁剪。
42. 风格选中态明显但不过度遮挡图片本身。
43. 桌面端 hover 风格说明文案完整可读；移动端不显示 hover 文案。
44. 风格名称为英文统一，描述简洁、无重复噪声。

### G. 账单与积分逻辑
45. 账单拆分显示：语言模型积分 + 图片模型积分 + 总计。
46. 语言模型积分按 token/字符估算，最少 1 积分。
47. 图片模型按 6 积分/标准输出计费，并显示原价 20 删除线。
48. 点击“确认生成”时必须真实扣积分，账单记录可追溯。
49. 余额不足时不可继续，提示应可理解并可引导升级。

### H. 生成与无限画布
50. 确认生成后，默认进入无限画布并聚焦第一个海报/分镜/PPT。
51. 生成状态可见：queued/generating/retrying/success/failed。
52. 单个任务失败时卡片显示简洁错误，可点击重试。
53. 自动重试次数生效，达到上限后进入失败态。
54. 生成成功后图片真实可见，不出现长期灰占位。
55. 重绘/下载按钮可用；下载文件命名规范。
56. 小屏场景可从聊天返回画布，入口明确可见。

### I. PPT / 视频导出
57. PPT 导出流程完整：准备 -> 图片 -> 页面 -> 文件。
58. 导出失败时错误可见，可重试。
59. 视频合成流程完整（含音轨）：准备 -> TTS -> 渲染 -> 封装。
60. 导出文件可下载且可打开（PPTX/MP4/WebM fallback）。

### J. 外链提取能力（YouTube/Podcast/Web）
61. Web URL 提取正文成功，内容进入后续文稿生成语境。
62. YouTube 链接字幕提取链路可用（下载/转写/回写）。
63. Podcast 链接提取链路可用（抓取/转写/回写）。
64. 无字幕/受限链接场景下，错误提示明确、可操作。
65. 免费用户遇到高阶模型依赖时，应弹付费引导而非静默失败。

### K. 异常与防刷
66. 高频请求触发 rate-limit 时，提示友好且不误伤正常操作。
67. 新建项目频次限制生效，超过阈值有明确文案。
68. 接口异常（5xx/timeout）有错误码，且用户可理解下一步操作。
69. Prompt/策略文本不在前端泄露（尤其系统提示词）。
70. 免费水印策略生效（仅免费用户注入，不暴露内部提示词）。

### L. 多端与响应式
71. 桌面（>=1280）布局稳定，无重叠、无错位。
72. 平板（768~1024）关键流程可完成，无功能缺失。
73. 手机（<=430）输入框固定底部，步骤流可滚动完成。
74. 横竖屏切换后，选中状态/草稿不丢失。

### M. 可访问性与可理解性
75. 关键按钮有可读文案，不依赖纯图标表达。
76. 错误信息一句话可懂，必要时附弱化错误码。
77. 焦点顺序正确，Tab 导航不陷入死区。
78. 颜色对比基本可读（尤其错误、警告、禁用态）。

## 4. 上线前“阻断项”（Go/No-Go）
- 任一 P0 未关闭：不可上线。
- 支付成功但未到账、或误扣积分：不可上线。
- 生成链路大面积失败（成功率 < 95%）：不可上线。
- 登录主链路失败率高（> 2%）且无兜底：不可上线。
- 移动端关键流程（输入->生成->下载）不可闭环：不可上线。

## 5. 建议的测试执行节奏
- 第 1 轮：核心链路冒烟（A/B/C/D/E/G/H）  
- 第 2 轮：外链与导出专项（I/J）  
- 第 3 轮：异常与防刷（K）  
- 第 4 轮：多端回归（L/M）  
- 每轮结束输出：缺陷列表 + 严重级 + 修复验证状态。
